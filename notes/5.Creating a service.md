## Calling our first service

As stated earlier, Services are one-time requests that should perform a one-time action, and the result of that action is returned as a response.

In this case , we'll be calling a service to save an image from the camera.

First, we need to install the image_view package, which contains the image_save node which allows us to save images 
```
sudo apt-get install ros-humble-image-view
```



```
ros2 run image_view image_saver --ros-args -p save_all_image:=false -r /image:=<camera_topic> -r /camera_info:=<camera_info_topic>
```

-r = Remap

-p = Parameter

we need to provide two topics , one for /image (like we did earlier)

another for /camera_info which ontains information about camera parameters such as resolution or data for image calibration.



to call save service --

```
ros2 service call /save std_srvs/srv/Empty {}
```
