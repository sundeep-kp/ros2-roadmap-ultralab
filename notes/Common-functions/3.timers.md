# Timers

### create_wall_timer()

**Description:** Creates a timer that executes a callback at a fixed interval.

**Syntax:**

```cpp
create_wall_timer(
    interval,
    callback
);
```

**Chatter Example:**

```cpp
timer_ =
    create_wall_timer(
        std::chrono::seconds(1),
        std::bind(
            &MyNode::timer_callback,
            this
        )
    );
```

Callback:

```cpp
void timer_callback()
{
    auto msg = std_msgs::msg::String();
    msg.data = "Hello ROS 2";

    publisher_->publish(msg);
}
```

**Remarks:**
- Commonly used for periodic publishing.
- Replaces manual loops and sleeps.
- Runs repeatedly until the node stops.
