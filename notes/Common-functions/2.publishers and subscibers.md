# Publishers

### create_publisher()

**Description:** Creates a publisher that can send messages to a topic.

**Syntax:**

```cpp
create_publisher<MessageType>(
    topic_name,
    queue_size
);
```
queue: 

In ROS 2, the queue size (the 10 in many examples) determines how many messages can be stored temporarily if the subscriber can't keep up with incoming messages.

ROS keeps the newest 10 messages until the subscriber processes them.
**Chatter Example:**

```cpp
publisher_ =
    create_publisher<std_msgs::msg::String>(
        "chatter",
        10
    );
```

**Remarks:**
- Usually called once in the constructor.
- Returns a publisher object used with `publish()`.

---

### publish()

**Description:** Sends a message on a topic.

**Syntax:**

```cpp
publisher_->publish(message);
```

**Chatter Example:**

```cpp
std_msgs::msg::String msg;
msg.data = "Hello ROS 2";

publisher_->publish(msg);
```

**Remarks:**
- Requires a valid publisher object.
- All subscribers on the topic receive the message.

# Subscribers

### create_subscription()

**Description:** Creates a subscriber that listens to a topic and executes a callback when a message arrives.

**Syntax:**

```cpp
create_subscription<MessageType>(
    topic_name,
    queue_size,
    callback
);
```

**Chatter Example:**

```cpp
subscription_ =
    create_subscription<std_msgs::msg::String>(
        "chatter",
        10,
        std::bind(
            &MyNode::topic_callback,
            this,
            std::placeholders::_1
        )
    );
```

**Remarks:**
- Usually called once in the constructor.
- Requires a callback function.

---

### std::bind()

**Description:** Connects a class member function to a callback interface.

**Syntax:**

```cpp
std::bind(
    &ClassName::function_name,
    this,
    std::placeholders::_1
);
```

**Chatter Example:**

```cpp
std::bind(
    &MyNode::topic_callback,
    this,
    std::placeholders::_1
)
```

Callback being connected:

```cpp
void topic_callback(
    const std_msgs::msg::String::SharedPtr msg)
{
    RCLCPP_INFO(
        get_logger(),
        "I heard: %s",
        msg->data.c_str()
    );
}
```

**Remarks:**
- Commonly used with subscriptions, timers, services, and actions.
- `std::placeholders::_1` represents the first argument passed to the callback (the message).
