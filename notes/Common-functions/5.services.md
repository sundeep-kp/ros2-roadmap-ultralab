# Services

### create_service()

**Description:** Creates a service server that waits for requests and sends responses.

**Syntax:**

```cpp
create_service<ServiceType>(
    service_name,
    callback
);
```

**Example:**

```cpp
service_ =
    create_service<std_srvs::srv::Empty>(
        "reset_counter",
        std::bind(
            &MyNode::reset_callback,
            this,
            std::placeholders::_1,
            std::placeholders::_2
        )
    );
```

**Remarks:**
- Used for request-response communication.
- Client asks once, server responds once.

---

### create_client()

**Description:** Creates a service client.

**Syntax:**

```cpp
create_client<ServiceType>(
    service_name
);
```

**Chatter Example:**

```cpp
client_ =
    create_client<std_srvs::srv::Empty>(
        "reset_counter"
    );
```

**Remarks:**
- Used to call a service.

---

### wait_for_service()

**Description:** Waits until the service becomes available.

**Syntax:**

```cpp
client_->wait_for_service(timeout_duration);
```
If the service becomes available within 1 second: true is returned.

Otherwise: false is returned.

**Example:**
```
while ( !client_->wait_for_service(std::chrono::seconds(1)) )
{
    RCLCPP_INFO(
        get_logger(),
        "Waiting for service..."
    );
}
```
**Remarks:**
- Prevents sending requests before the server exists.

---

### async_send_request()

**Description:** Sends a service request.

**Syntax:**

```cpp
client_->async_send_request(
    request
);
```

**Example:**

```cpp
auto request =
    std::make_shared<
        std_srvs::srv::Empty::Request>();

client_->async_send_request(
    request
);
```

**Remarks:**
- Usually returns a future.
- Non-blocking.

## Common service types
| Service Type                          | Request Fields                        | Response Fields                    | When to Use                                                                      |
| ------------------------------------- | ------------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------- |
| `std_srvs::srv::Trigger`              | *(none)*                              | `bool success`<br>`string message` | Execute an action without parameters (start robot, reset sensor, save map, etc.) |
| `std_srvs::srv::SetBool`              | `bool data`                           | `bool success`<br>`string message` | Turn something on/off, enable/disable features                                   |
| `std_srvs::srv::Empty`                | *(none)*                              | *(none)*                           | Simple signal with no data exchanged (less common in ROS 2)                      |
| `example_interfaces::srv::AddTwoInts` | `int64 a`<br>`int64 b`                | `int64 sum`                        | Learning ROS services; simple arithmetic examples                                |
| `example_interfaces::srv::SetBool`    | `bool data`                           | `bool success`<br>`string message` | Similar to `std_srvs::srv::SetBool` (check package availability)                 |
| `rcl_interfaces::srv::GetParameters`  | `string[] names`                      | `ParameterValue[] values`          | Read node parameters remotely                                                    |
| `rcl_interfaces::srv::SetParameters`  | `Parameter[] parameters`              | `SetParametersResult[] results`    | Modify node parameters at runtime                                                |
| `rcl_interfaces::srv::ListParameters` | `string[] prefixes`<br>`uint64 depth` | Parameter names and prefixes       | Discover available parameters                                                    |
| `nav_msgs::srv::GetMap`               | *(none)*                              | `OccupancyGrid map`                | Retrieve a map from a mapping/localization node                                  |
| `lifecycle_msgs::srv::ChangeState`    | `Transition transition`               | `bool success`                     | Move lifecycle nodes between states                                              |
| `lifecycle_msgs::srv::GetState`       | *(none)*                              | Current lifecycle state            | Check node lifecycle status                                                      |
