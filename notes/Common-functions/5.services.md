# Services

### create_service()

**Description:** Creates a service server that waits for requests and sends responses.

**Syntax:**

```cpp
create_service<ServiceType>(
    service_name,
    callback
);
```

**Example:**

```cpp
service_ =
    create_service<std_srvs::srv::Empty>(
        "reset_counter",
        std::bind(
            &MyNode::reset_callback,
            this,
            std::placeholders::_1,
            std::placeholders::_2
        )
    );
```

**Remarks:**
- Used for request-response communication.
- Client asks once, server responds once.

---

### create_client()

**Description:** Creates a service client.

**Syntax:**

```cpp
create_client<ServiceType>(
    service_name
);
```

**Chatter Example:**

```cpp
client_ =
    create_client<std_srvs::srv::Empty>(
        "reset_counter"
    );
```

**Remarks:**
- Used to call a service.

---

### wait_for_service()

**Description:** Waits until the service becomes available.

**Syntax:**

```cpp
client_->wait_for_service(timeout_duration);
```
If the service becomes available within 1 second: true is returned.

Otherwise: false is returned.

**Example:**
```
while ( !client_->wait_for_service(std::chrono::seconds(1)) )
{
    RCLCPP_INFO(
        get_logger(),
        "Waiting for service..."
    );
}
```
**Remarks:**
- Prevents sending requests before the server exists.

---

### async_send_request()

**Description:** Sends a service request.

**Syntax:**

```cpp
client_->async_send_request(
    request
);
```

**Example:**

```cpp
auto request =
    std::make_shared<
        std_srvs::srv::Empty::Request>();

client_->async_send_request(
    request
);
```

**Remarks:**
- Usually returns a future.
- Non-blocking.
