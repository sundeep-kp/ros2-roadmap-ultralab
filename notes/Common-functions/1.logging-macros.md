## What is a Macro?

A **macro** is a piece of code that the C++ preprocessor replaces with other code before compilation.



## What is Logging?

Logging is the process of printing messages about what your program is doing.

Instead of:

```cpp
std::cout << "Motor Started" << std::endl;
```

ROS 2 uses:

```cpp
RCLCPP_INFO(get_logger(), "Motor Started");
```

Advantages:

- Includes timestamps
- Includes logger names
- Supports filtering by severity level
- Integrates with ROS tools



## Logging Levels *

ROS 2 provides different severity levels.

| Macro | Level | Use Case |
|---------|---------|---------|
| `RCLCPP_DEBUG` | Debug | Detailed debugging information |
| `RCLCPP_INFO` | Info | Normal operation messages |
| `RCLCPP_WARN` | Warning | Something unexpected happened |
| `RCLCPP_ERROR` | Error | An error occurred |
| `RCLCPP_FATAL` | Fatal | Critical failure |

Example:

```cpp
RCLCPP_DEBUG(get_logger(), "Debug");
RCLCPP_INFO(get_logger(), "Started");
RCLCPP_WARN(get_logger(), "Battery low");
RCLCPP_ERROR(get_logger(), "Sensor failed");
RCLCPP_FATAL(get_logger(), "System crash");
```

## Printing Variables

`RCLCPP_INFO` works similarly to `printf()`.

### Integer

```cpp
int count = 5;

RCLCPP_INFO(get_logger(), "Count = %d", count);
```

Output:

```text
Count = 5
```

### Float

```cpp
float temp = 36.5;

RCLCPP_INFO(get_logger(), "Temperature = %.2f", temp);
```

Output:

```text
Temperature = 36.50
```

### String

```cpp
std::string name = "Sundeep";

RCLCPP_INFO(get_logger(), "Name = %s", name.c_str());
```

Output:

```text
Name = Sundeep
```

---

## Common Format Specifiers

| Specifier | Type |
|------------|------------|
| `%d` | Integer |
| `%f` | Float/Double |
| `%.2f` | Float with 2 decimal places |
| `%s` | String |
| `%c` | Character |
| `%x` | Hexadecimal |

Multi variable Example:

```cpp
int age = 18;
float voltage = 12.56;

RCLCPP_INFO(
    get_logger(),
    "Age=%d Voltage=%.2f",
    age,
    voltage
);
```

## Stream-Style Logging

Instead of format specifiers:

```cpp
RCLCPP_INFO(
    get_logger(),
    "Count = %d",
    count
);
```

you can use stream-style logging:

```cpp
RCLCPP_INFO_STREAM(
    get_logger(),
    "Count = " << count
);
```

Similar to:

```cpp
std::cout << "Count = " << count;
```

Useful when printing many variables or objects.

# Types of Loggers

The first argument of `RCLCPP_INFO()` is a logger.

```cpp
RCLCPP_INFO(logger, "Message");
```

Different logger types can be used.

---

## 1. Node's Default Logger

Most common logger.

```cpp
RCLCPP_INFO(this->get_logger(), "Hello");
```

If the node name is:

```cpp
my_node
```

Output:

```text
[my_node]: Hello
```

Use when:
- Small nodes
- General logging

---

## 2. Creating a Named Logger

Create a logger with your own name.

```cpp
auto logger =
    rclcpp::get_logger("motor_controller");

RCLCPP_INFO(logger, "Motor started");
```

Output:

```text
[motor_controller]: Motor started
```

Use when:
- A large node contains multiple subsystems
- You want logs independent of the node name

Examples:

```cpp
motor_controller
camera
navigation
lidar
```

---

## 3. Child Loggers

Create sub-loggers from an existing logger.

```cpp
auto sensor_logger =
    get_logger().get_child("sensor");

auto camera_logger =
    get_logger().get_child("camera");
```

Usage:

```cpp
RCLCPP_INFO(sensor_logger, "Reading sensor");
RCLCPP_INFO(camera_logger, "Capturing image");
```

Output:

```text
[my_node.sensor]: Reading sensor
[my_node.camera]: Capturing image
```

Use when:
- One node contains multiple components
- You want organized logs

Example robot structure:

```text
spider_controller.gait
spider_controller.vision
spider_controller.motor
spider_controller.ai
```

---

## 4. Static / Global Loggers

Useful in helper classes that are not ROS nodes.

```cpp
static auto logger =
    rclcpp::get_logger("motor_driver");

RCLCPP_INFO(logger, "Started");
```

Use when:
- Utility classes
- Hardware drivers
- Libraries
- Code that does not inherit from `rclcpp::Node`

Example:

```cpp
class MotorDriver
{
public:
    void start()
    {
        static auto logger =
            rclcpp::get_logger("motor_driver");

        RCLCPP_INFO(logger, "Motor started");
    }
};
```

---

# Quick Rule of Thumb

| Situation | Logger Type |
|------------|------------|
| Normal node logging | `get_logger()` |
| Large subsystem | Named logger |
| Component inside a node | Child logger |
| Non-node helper class | Static/global logger |

Most beginner ROS 2 code uses:

```cpp
RCLCPP_INFO(get_logger(), "Message");
```

As projects grow larger, child loggers become extremely useful for debugging.
