# Parameters

### declare_parameter()

**Description:** Creates a parameter and gives it a default value.

**Syntax:**

```cpp
declare_parameter(
    parameter_name,
    default_value
);
```

**Example:**

```cpp
declare_parameter(
    "message_text",
    "Hello ROS 2"
);
```

**Remarks:**
- Usually called in the constructor.
- Parameter must generally be declared before use.

---

### get_parameter()

**Description:** Reads a parameter value.

**Syntax:**

```cpp
get_parameter(parameter_name);
```

**Example:**

```cpp
std::string text =
    get_parameter("message_text")
        .as_string();
```

**Remarks:**
- Returns a Parameter object.
- Usually followed by `.as_string()`, `.as_int()`, etc. unless you deliberately want it as a parameter object

---

### set_parameter()

**Description:** Changes a parameter value.

**Syntax:**

```cpp
set_parameter(
    rclcpp::Parameter(
        parameter_name,
        value
    )
);
```

**Example:**

```cpp
set_parameter(
    rclcpp::Parameter(
        "message_text",
        "New Message"
    )
);
```

**Remarks:**
- Can be called during runtime.

> ### I had a doubt here-- why specify rclcpp::Parameter?
>Because set_parameter() expects a Parameter object, not just a name and value separately. So you create one:
```
rclcpp::Parameter(
    "message_text",
    "Hello ROS 2"
)
```
> you may skip this if you already have a parameter object like 
```
auto t = get_parameter("example_parameter");
```
---

### has_parameter()

**Description:** Checks whether a parameter exists.

**Syntax:**

```cpp
has_parameter(parameter_name);
```

**Example:**

```cpp
if (has_parameter("message_text"))
{
    // use parameter
}
```

**Remarks:**
- Returns `true` or `false`.
